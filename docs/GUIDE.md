# 拾回 使用指南

## 1. 首次打开后

首次打开后，如无法读取废纸篓，前往“系统设置 → 隐私与安全性 → 完全磁盘访问权限”添加拾回，再退出并重新打开。

## 2. 连接需要查看的外置磁盘

连接需要查看的外置磁盘，等待后台读取；使用搜索查找名称或记录的来源路径。

## 3. 选择文件后查看来源、大小、时间和标签

选择文件后查看来源、大小、时间和标签，使用列表表头调整排序。

## 4. 来源可靠时使用“放回原处”；来源未知时使用恢复到指定文件夹。

来源可靠时使用“放回原处”；来源未知时使用恢复到指定文件夹。

## 5. 恢复成功后在 Finder 中核对实际文件；目标重名的文件会跳过

恢复成功后在 Finder 中核对实际文件；目标重名的文件会跳过，不覆盖。

## 6. 确实不需要的项目可永久删除

确实不需要的项目可永久删除，清倒废纸篓前检查确认框。

## 7. 关闭窗口不等于退出；从菜单栏垃圾桶入口重新打开

关闭窗口不等于退出；从菜单栏垃圾桶入口重新打开，选择“退出拾回”结束监测。

## 操作边界

- 不是磁盘数据恢复软件，不能找回已彻底删除或被覆盖的数据。
- 无法确认来源时显示未知，不根据同名文件猜测原路径。
- 权限、文件系统、历史保留情况及外置磁盘连接状态会影响来源识别。
- 文件夹大小不递归统计，不代表能够释放的真实磁盘空间。
- 永久删除和清倒不可恢复。本版确认框回车默认执行，Esc 取消，请认真核对。
- 未提供安全擦除、强制清空、自动清空或删除保护。
